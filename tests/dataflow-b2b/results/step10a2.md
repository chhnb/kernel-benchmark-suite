## 修改前诊断

三个区域逐对比较了 anchor 选中布局记录的 `source_pairs` 与统一生成器收到的左右操作索引和对应方式。两边都是空配对，且三个 anchor 尝试的 `rewrite_started=false`。选中布局虽标为 `before-split`，实际没有合并或提出前缀，也没有生成分段 fork-join、合并出口或重排访存。

| `e7ea914e85` | (448, 165, 290) | (392, 138, 261) | 64 → 0 | 182 / 203 → 183 / 210 |
| `e358322793` | (448, 165, 290) | (392, 138, 261) | 64 → 0 | 182 / 203 → 183 / 210 |

公共列包括输入区域原有的分支前地址计算。两侧新增推测数为零。两种生成均有 1 个保护分支、2 个保护段、0 个 select 和 0 个流出值。单独重放 EarlyCSE 就复现全部收益。分别重放 DCE，以及在 EarlyCSE 后再跑 DCE 和 InstCombine，均无额外成本变化。指令差异全部来自 GEP。第一个区域公共 GEP 净减 256，左、右保护块分别净增 1、15，分歧指令价净降 240。另两个区域公共 GEP 各净减 64，两臂分别净增 1、7，分歧指令价净降 56。控制与访存项保持相同。统一生成补上同等清理和空配对原保护布局的报价。
