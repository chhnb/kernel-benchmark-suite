# 区域 Anchor 的 GEP、PHI 与 DARM 对照

基线为 `69c19ae`。回放使用 LLVM24 latency、`--region-align anchor --merge-metadata intersect --region-memory-pairing e3 --anchor-gap-order sw`。新增 `--region-anchor-pair-phi` 默认为关闭。

## 1. GEP 17/12 的代价

共享 store L34/R14 的左指针是 L33 的 %177，右指针是 R12 的 %281。L17 的 %162 供左侧 L18 的单侧 store 使用。因此配对 L17/R12 后的地址仍与 L33 不同，共享 store 仍要选择指针。

| 规划项 | 跳过 L17/R12 | 配 L17/R12 |
|---|---:|---:|
| 共享 store 的 E3 收益 | +100 | +100 |
| 共享 store 的指针 select | −1 | −1 |
| 共享 store 的数据 select | −1 | −1 |
| 共享 GEP 的收益 | 0 | +1 |
| 共享 GEP 的基址 select | 0 | 0（同为 %129） |
| 共享 GEP 的 index select | 0 | −1 |
| 新增分段 | 0 | −2 |
| 这部分净贡献 | 98 | 96 |

其余 6 对 GEP（49/27、65/42、81/57、97/72、113/87、129/102）确实对应共享 store 的两个指针生产者。补配后，store 指针 select 从 1 降到 0。合计 GEP +1、index select −1、分段 −2、下游指针 select +1，净变动 −1，与逐对探针一致。前向 `addedCost` 查询已配对的生产者，因此现有模型已经计入指针选择的节省。B2B 共用该逻辑。B2B 的反向判断也为已配对或可继续传播的输入免除 select，兼容性检查和成本独立。没有新增指针抵扣开关。

## 2. PHI 配对

原型提交 `0a37fe4` 在 `alignRegionBlocks` 构建工作列表时排除 PHI，并把两侧 PHI 分别附到序列头。提交说明未单独解释排除理由。代码里的边界是 DARM 自己独立克隆、修复两侧 PHI，即使其对齐序列把 PHI 标成一对。

开启后，匹配的区域入口或两侧循环头可做 PHI 前缀 DP。前驱须可逐条对应，按 PHI 报价减去不同入值所需 select，沿用严格/宽松两种零收益处理。PHI 序列配对继续由 DARM 发射器独立修复两侧。块内规划不把这类序列配对视为共同 SSA 值。小型循环正例的 lp/rp 在 throughput 下形成一个零收益配对并通过 LLVM verifier。

PCM32 的 L1/R1、L2/R2、L3/R3 均有两条不同的入边 SSA 值。latency PHI 报价为 0，两个 i32 select 各 1，所以三对都是 −2，均未入选。

## 3. PCM32

开关前后 cleanup IR、O3 IR（除输出路径所致的 ModuleID 行）和 HSACO 一致。两份产物均与 DARM 的 IR 和 HSACO 不同。与上轮一样，剩余的 11 项序列差异是 3 对 PHI、7 对 GEP 和 1 对取值 select，SW 单侧排列仍已对齐。

cleanup 后整个目标函数的 DARM / Anchor 统计为 1090 / 1089 条指令、67 / 65 条 PHI、88 / 88 条 select、31 / 31 条条件分支、98 / 98 条 LDS load、81 / 81 条 LDS store。LLVM24 latency TTI 为 1665 / 1669。

PCM32 A/A 1 最大跨度 1.16%。

## 结论

区域融合继续使用 DARM。26 次区域融合中，Anchor 为 0 赢、20 平、5 输，另有 1 次不确定。5 次确认退化均少配了 2 对向量 FMA 和 12 对向量拼拆指令，伴随 VGPR 使用量上升和静态 occupancy 下降。其中 2 次在 mixed 输入上确认退化，coherent 输入的 A/A 未通过。另有两次同样出现寄存器压力上升但未确认退化。

在 PCM32 的同一 E3 配对集合下，`sw` 交织把相对 DARM 的差距从 3.16% 缩到 0.69%，解释了约 78% 的原差距。单侧指令应尽量靠近使用它的配对。

PCM32 剩余的 0.69% 差距对应 3 对 PHI、7 对 GEP 和 1 对 select 的配对差异。按当前打分，补入其中任一对都小亏，结束对这 11 对的追查。
