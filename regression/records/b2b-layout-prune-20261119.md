# B2B 布局裁剪

移除 `binary-common-dp` 及 `searchB2BCommon` 的二元操作特例。该布局在 A 的九个编译 case 共生成七次，均未达到候选内最高分。其余布局继续保留，实例位于 [布局审计](b2b-layout-usage-20261119.md)。
Recipe 升为 v3。回归明确验证 v2 recipe 在当前工具中被拒绝。

trial 数来自实际布局克隆阶段调用计数，评分数来自去重后的调用计数。两边使用原生实时 LLVM24 worker。搜索秒数是对应单次并行运行的墙钟时间，供定位开销。
