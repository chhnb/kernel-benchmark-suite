--frontend rebuilds from the retained source. Without it, build starts with the
frozen full-kernel O3 IR. --roles accepts a comma-separated subset of:
 baseline: no fusion, common final cleanup
 darm_auto: original Git default full automatic fusion
 full_xy: same original merger, choose initial XY, retain outside automatic melds

same final cleanup. XY requires cleanup/re-entry before final Z. All build outputs
must be fresh, retain commands/logs, and compare final .text against frozen validated
references. A mismatch fails closed and needs review/new correctness, never inherited
acceptance. No GPU job is started by any of these commands.
